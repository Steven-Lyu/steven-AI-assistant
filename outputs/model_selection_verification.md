# 模型配置修复（2026-11-12）

## 原因与改动

Make plan 报 `model_not_found`：本机 Codex 全局配置指定 `gpt-6-sol`，应用未显式选择模型，因此继承该值；当前 ChatGPT 账户的实际请求拒绝了它。

应用现在在每次规划时读取 app-server `model/list`（支持分页），显式使用目录默认模型，并采用返回的默认推理强度。`CODEX_MODEL` 仍可覆盖，但必须在可见目录中。空目录、无效覆盖及异常分页直接失败，避免隐式回退到全局配置。Activity 记录所选模型。未修改用户全局 Codex 配置。

协议依据：[官方 app-server 模型文档](https://learn.chatgpt.com/docs/app-server)。模型目录不等同于账户权限检查；实际推理成功才验证该次请求可用。
